
# Cross-Battery Approach (X-BASS 3.0) Interpretation Drafting

## Summary

This skill generates professional narrative interpretations for cognitive abilities evaluated via the Cross-Battery Assessment (X-BASS 3.0) framework.

## When to Use

Use when drafting psychoeducational evaluation reports requiring cross-battery cognitive processing narratives across CHC broad abilities (Gc, Gf, Gsm, Glr, Gv, Ga, Gs).

## Steps

1. Review cognitive test scores across administered batteries included in the cross-battery analysis.
2. Draft domain-specific narrative statements for each CHC cognitive area assessed.
3. Populate standard score (SS) and percentile rank (PR) data into the template structure.
