
# Woodcock-Johnson IV Tests of Cognitive Abilities Interpretation Drafting

## Summary

This skill generates professional narrative interpretations for cognitive abilities evaluated via the Woodcock-Johnson IV Tests of Cognitive Abilities based on the CHC model.

## When to Use

Use when drafting psychoeducational evaluation reports incorporating WJ-IV cognitive assessment results across primary CHC broad factors.

## Steps

1. Review individual cognitive cluster scores from the WJ-IV assessment.
2. Populate domain-specific narrative templates for Gc, Gf, Gsm, Glr, Gv, Ga, and Gs.
3. Include standard scores (SS) and percentile ranks (PR) for each domain.
