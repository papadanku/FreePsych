
# Wechsler Intelligence Scale for Children · Fifth Edition (WISC-V) Interpretation Drafting

## Summary

This skill generates professional narrative interpretations for cognitive indices and domain scores evaluated via the WISC-V assessment.

## When to Use

Use when drafting psychoeducational evaluation reports incorporating WISC-V primary indices (Gc, Gv, Gf, Gs, Gsm) and composite scores (NVI, GAI, CPI).

## Steps

1. Review standard scores and percentile ranks for WISC-V primary indices and composite scores.
2. Populate domain-specific narrative statements into the report template.
3. Ensure student name and performance classifications are properly filled.
