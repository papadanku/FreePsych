
# Kaufman Assessment Battery for Children – II Normative Update Interpretation Drafting

## Summary

This skill generates professional narrative interpretations for cognitive abilities evaluated via the KABC-II NU, including global indexes (FCI, NVI) and CHC broad cognitive domains.

## When to Use

Use when drafting psychoeducational evaluation reports incorporating KABC-II NU test results.

## Steps

1. Review global index scores (Fluid-Crystallized Index or Nonverbal Index) and domain-specific index scores.
2. Draft narrative statements incorporating student demographics and performance ranges.
3. Populate standard scores (SS) and percentile ranks (PR) where applicable.
