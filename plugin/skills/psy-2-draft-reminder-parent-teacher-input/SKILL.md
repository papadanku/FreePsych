# Parent and Teacher Evaluation Input Requests

Generate professional email inquiry templates to gather input from both teachers and parents or guardians for a student undergoing a psychoeducational evaluation or re-evaluation.

## When to Use

Use this skill when a student is undergoing an evaluation or re-evaluation and you need to contact:

- Teachers for updates on classroom progress, grades, work habits, and behavior.
- Parents or guardians for updates on home background, health history, and social background.

## Instructions

1. Output **both** inquiry versions (Teacher Version and Parent/Guardian Version) by default so both outreach emails are ready to use.
2. Preserve the generic placeholders in the body and footer (do not fill in fabricated names, emails, phone numbers, or school names unless the user provides them).

## Template Content

### Teacher Version (Classroom Progress Request)

```
Hello,

The following student is currently undergoing a re-evaluation. The [School Name] SPED team requests your input regarding updates to the student's classroom progress.

If you have any questions, please contact me using the information below.

---

[Your Name]
[Your Email] | [Your Phone Number]
[School District] | [School Name]
```

### Parent/Guardian Version (Home Background Request)

```
Hello,

The [School Name] SPED team requests your input regarding updates to the student's home background.

If you have any questions, please contact me using the information below.

---

[Your Name]
[Your Email] | [Your Phone Number]
[School District] | [School Name]
```
