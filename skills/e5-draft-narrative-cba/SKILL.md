# X-BASS Cognitive Broad Ability Cohesion Narrative Generator

## Summary

This skill generates formal psychoeducational report narratives regarding the unitary or non-unitary nature of Cattell-Horn-Carroll (CHC) cognitive broad abilities using Cross-Battery Assessment (X-BASS) methodology.

## When to Use

Use when drafting psychoeducational reports and generating clinical interpretation narratives for cognitive broad abilities (Gc, Gf, Gsm, Glr, Gv, Ga, Gs) evaluated via X-BASS methodology.

## Instructions & Workflow

1. **Review Input Data:** Analyze the cognitive assessment scores and identify which broad abilities were found to be non-unitary (not cohesive) based on core battery subtests alone.
2. **Select Applicable Options:** Choose the appropriate narrative templates corresponding to each broad ability's status following confirmation/supplemental testing:
    - **Standard Opening:** State the initial non-unitary findings, confirmation testing batteries utilized (e.g., WJ-IV, KABC-II, WISC-V, CTOPP-2), and application of X-BASS (Flanagan, Ortiz, and Alfonso, 2017) adjusted mean scores.
    - **Option 1 (Not Cohesive but Average):** Use when broad abilities remain non-unitary after supplemental testing, but contributing scores fall within the Average range (no additional testing warranted).
    - **Option 2 (Identification of Specific Weakness):** Use when non-unitary results suggest a specific cognitive weakness in a narrow ability, while other areas fall within the Average range.
    - **Option 3 (Cohesive vs. Non-Unitary Average Results):** Use when abilities become unitary (cohesive) after supplemental testing, or contrast multiple findings.
3. **Replace Placeholders:** Ensure all placeholders (`??` or `Gx`) are replaced with correct CHC terminology (e.g., *Auditory Processing* for Ga, *Short-Term Working Memory* for Gsm).
4. **Maintain Tone:** Keep all generated narratives strictly academic, objective, and professional.
