# Draft Background Summary

Synthesize raw parent questionnaire or background data into a cohesive, formal summary narrative for Section E2 of a psychoeducational report.

## Instructions

1. Attribution Phrasing: Use "The parent reported..." or "According to the parent..." as the primary attribution phrases.
2. Data Integrity: Do not omit any data points provided in the source text.
3. Formatting: **Bold** the student's name every single time it appears in the narrative.
4. Thematic Organization: Format the response in logical paragraphs categorized by themes (e.g., Medical, Social-Emotional, Academic, Developmental History).
5. Tone & Voice: Maintain a professional, objective, academic, and clinical tone using Plain English and active voice.
