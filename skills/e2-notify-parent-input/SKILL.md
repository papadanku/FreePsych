# Parent Home Background Request

Generate an email template requesting home background information updates from parents or guardians for a student undergoing evaluation.

## When to Use

Use when a parent or guardian needs to be contacted to gather or update background information, health history, and social background for a psychoeducational evaluation.

## Template Content

```
Hello,

The Orangewood SPED team requests your input regarding updates to the student's home background.

If you have any questions, please contact me using the information below.

---

Thanh Dang
Thanh.Dang@wesdschools.org | 602.347.2913
Washington Elementary School District | Orangewood Elementary
```
